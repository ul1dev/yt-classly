# Classly — эксперимент с вайбкодингом

Classly — демо-приложение для студии групповых занятий. В нём есть расписание двух филиалов, клиенты, записи на занятия и абонементы. Владелец и администраторы могут управлять занятиями и клиентами.

## Зачем я это сделал

Я хотел проверить идею «описал приложение словами — и быстро получил готовый продукт». Почти весь проект я собрал через вайбкодинг: писал запросы, запускал полученный код, исправлял ошибки и добавлял новые функции.

Для прототипа такой подход действительно работает: приложение запускается и им можно пользоваться. Но когда проект растёт, мало заставить каждую отдельную функцию работать. Нужно понимать, как устроена вся система и как сегодняшнее решение повлияет на следующие изменения. Вайбкодинг помогает быстро проверить идею, но не заменяет знания кода и умения выстроить архитектуру большого проекта.

Это учебный прототип и материал для эксперимента, а не готовый сервис для работы с реальными клиентскими данными.

## Как запустить

Нужен Node.js. Установите зависимости и создайте файл настроек:

```bash
npm ci
cp .env.example .env
```

Укажите в `.env` почту владельца (`ADMIN_EMAIL`) и bcrypt-хеш его пароля (`OWNER_PASSWORD_HASH`). Хеш можно создать командой:

```bash
node -e "console.log(require('bcryptjs').hashSync('ваш-пароль', 12))"
```

В `.env` заключите полученный хеш в одинарные кавычки, чтобы сохранить символы `$`. Затем запустите приложение:

```bash
npm run dev
```

Откройте `http://localhost:5173`. Данные сохраняются в локальной базе SQLite. Для проверки проекта доступны `npm test` и `npm run build`.
