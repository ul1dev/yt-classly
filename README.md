# Студия

Русскоязычное приложение для расписания, клиентов и записей групповой студии.

## Локальный запуск

1. Установите зависимости: `npm install`.
2. Создайте bcrypt-хеш пароля: `node -e "console.log(require('bcryptjs').hashSync('ВАШ-ДЛИННЫЙ-ПАРОЛЬ', 12))"`.
3. Скопируйте `.env.example` в `.env` и заполните `OWNER_PASSWORD_HASH`. В файле `.env` заключите bcrypt-хеш в одинарные кавычки, чтобы символы `$` сохранялись буквально.
4. Запустите `npm run dev` и откройте `http://localhost:5173`.

Данные хранятся в SQLite по пути `DB_PATH` (по умолчанию `./data/studio.db`). При первом запуске база получает демонстрационные занятия, клиентов и записи. В дальнейшем данные не перезаписываются.

## Размещение на VPS

Направьте DNS-запись домена на сервер, установите Docker Compose, заполните `.env` с `DOMAIN` и `OWNER_PASSWORD_HASH`, затем запустите `docker compose up -d --build`. Caddy автоматически обслуживает HTTPS. База хранится в томе `studio-data`; включите этот том в резервное копирование. Порты 80 и 443 должны быть доступны извне.

## Проверка

`npm test` — правила записей и сохранность базы. `npm run build` — проверка TypeScript и производственная сборка.
